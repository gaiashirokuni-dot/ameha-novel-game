AMEHA NOVEL GAME - GitHub Pages用プロトタイプ

【内容】
・2人のセラピストによるマルチエンディング
・選択肢4問
・名前入力
・NAYUTA END / GORILLA END
・簡易個別ルート
・プロフィールページへのリンク
・発見済みENDをlocalStorageで端末内に保存

【GitHub Pagesへの設置】
1. GitHubでPublicリポジトリを作成
2. ZIPを解凍し、中身をリポジトリのルートへアップロード
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / Folder: /(root)
6. Save
7. 発行されたURLをJimdoのiframeから呼び出す

【重要】
ZIPそのものではなく、解凍後の index.html / css / js / assets をルートに置いてください。
